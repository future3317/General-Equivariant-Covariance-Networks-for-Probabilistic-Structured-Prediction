# Documentation archive — 2026-08-18

This archive preserves completed pilots, superseded evidence ledgers, and
executed planning/specification documents that no longer define the current
research path. Files were moved from `docs/` without rewriting their contents,
so the original record remains recoverable through Git history and this
bounded archive.

## Why these files are here

- **Pilots and phase gates:** E1/E2/E3a, objective-coupling, and early repair
  documents are development or stopped-gate records.
- **Superseded audits:** older uncertainty, reviewer, and performance ledgers
  have been consolidated into the current evidence documents listed in
  [`docs/README.md`](../../README.md).
- **Executed plans/specifications:** the `superpowers/` subtree records the
  implementation history; it is not a second set of active instructions.

The archive contains no datasets, checkpoints, generated result payloads, or
private run artifacts.
